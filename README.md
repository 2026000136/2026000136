# 🎓 대학교 학과 복합 다중 게시판 커뮤니티 시스템

바이브 코딩(Vibe Coding) 기법과 AI 에이전트(Antigravity) 페어 프로그래밍을 통해 구축된 **대학교 학과별 복합 다중 게시판 및 소통 포털 웹 애플리케이션**입니다.

---

## 📌 1. 프로젝트 개요
- **개발 환경**: Node.js v26.13.0, Vanilla JS, HTML5, CSS3, `node:sqlite` (SQLite 내장 모듈)
- **외부 의존성 제로**: 별도의 무거운 외부 패키지(`npm install`) 없이 순수 Node.js 내장 모듈(`http`, `node:sqlite`, `crypto`, `fs`, `path`)만으로 작동하여 어떤 환경에서도 즉시 구동 가능
- **아키텍처**: Multi-Tenant 복합 다중 공간(Spaces) - 다중 게시판(Boards) - 회원(Users) - 게시글(Posts) - 댓글(Comments) 데이터 격리 구조

---

## 🚀 2. 빠른 실행 방법

### Windows 환경:
1. 본 레포지토리를 클론하거나 다운로드합니다.
2. 폴더 내의 **`실행하기.bat`** 파일을 더블 클릭합니다.
   - 서버가 켜짐과 동시에 브라우저([http://localhost:3000](http://localhost:3000))가 자동으로 열립니다.

### 콘솔 환경:
```bash
node server.js
```
실행 후 브라우저에서 `http://localhost:3000` 접속

## ✨ 4. 구현된 주요 기능

1. **운영 공간(Spaces) 관리**:
   - 최고 관리자의 학과/조직 운영 공간 생성 및 삭제
   - 각 공간별 담당 관리자(`space_admin`) 지정
2. **공간별 독립 다중 게시판(Boards)**:
   - 각 운영 공간마다 독립적인 게시판 목록 보유 (예: 컴퓨터공학과의 공지/자유/질문 게시판, 디자인학과의 공지/작품공유/자유 게시판 등)
   - 공간 관리자의 게시판 개설, 이름 및 설명 수정, 게시판 삭제(연쇄 삭제)
3. **게시판별 게시글 격리 및 조회**:
   - 특정 게시판에 작성된 글이 다른 게시판이나 타 학과 공간에 절대 노출되지 않는 엄격한 데이터 분리
   - 최신순 정렬 및 상단 고정 공지사항(`📢 공지`) 지원
4. **회원 인증 및 본명 연동**:
   - 회원가입 시 입력한 실명이 모든 게시글과 댓글의 작성자명으로 자동 반영
5. **게시글 및 댓글 CRUD & 보안 권한 통제**:
   - 작성자 본인만 게시글/댓글 수정 및 삭제 가능
   - 공간 관리자는 본인 공간 내 부적절한 게시글/댓글 관리 삭제 가능
   - 타 운영 공간의 데이터나 회원 명부 열람 시도 시 서버(403 Forbidden)에서 원천 차단
6. **모바일 반응형 웹 UI**:
   - PC(2열 레이아웃: 사이드바 + 피드) 및 모바일(1열 맞춤형 반응형 디자인) 지원

## 📂 5. 프로젝트 구조
```
├── server.js               # Node.js 내장 HTTP 서버 및 REST API 라우터 (보안 가드 포함)
├── db.js                   # node:sqlite 기반 정규화 DB 스키마 및 CRUD 쿼리 엔진
├── database.sqlite         # SQLite 실제 데이터베이스 파일 (영구 보존)
├── 실행하기.bat            # 윈도우 원클릭 서버 실행 및 브라우저 자동 오픈 스크립트
├── public/                 # 프론트엔드 정적 리소스
│   ├── index.html          # 단일 페이지 애플리케이션(SPA) 반응형 뷰 구조
│   ├── styles.css          # 현대적 대학 커뮤니티 테마 및 반응형 CSS
│   └── app.js              # 클라이언트 라우터, 상태 관리 및 비동기 API 통신 로직
├── PROMPTS_AND_LOGS.md     # 바이브 코딩 프롬프트 히스토리 및 AI 에이전트 응답 분석서
└── README.md               # 프로젝트 안내서 (본 파일)
```
